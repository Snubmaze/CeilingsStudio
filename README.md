# Сайт частного мастера по натяжным потолкам

React / Vinext, Tailwind CSS, Framer Motion, Radix UI.

Контакты, услуги, примеры работ, отзывы, FAQ и коэффициенты калькулятора находятся в `app/site-data.ts`. Замените `[ИМЯ МАСТЕРА]`, `[ТЕЛЕФОН]`, ссылки на мессенджеры и остальные плейсхолдеры.

Главное условие: полная постоплата после монтажа. Связь — напрямую по телефону, через Telegram или WhatsApp. На сайте нет форм, сбора заявок, API для лидов и карты. Калькулятор показывает ориентир без ввода контактов.

Фото интерьеров и отзывы — демонстрационные материалы, помеченные на странице. Источники фото доступны в подвале. Перед коммерческим запуском замените их подтверждёнными материалами мастера с правом публикации.

Запуск: `npm run dev`. Сборка: `npm run build`.
