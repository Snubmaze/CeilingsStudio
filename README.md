# Лендинг натяжных потолков

React / Next-compatible Vinext, Tailwind CSS, Framer Motion, Radix UI.

## Редактирование

Контакты, основные тексты, цены, калькулятор, проекты, вопросы и документы: `app/site-data.ts`.
Секции и формы: `app/page.tsx`. Стили и адаптивность: `app/globals.css`.

Изображения — интерьерные референсы сторонних авторов, не работы компании. Источники доступны в подвале. Перед публичным коммерческим использованием замените собственными лицензированными фото. Проекты, отзывы и цифры отмечены как демонстрационные; замените подтверждёнными данными, заполните [N], контакты и юридические документы.

## Формы

POST `/api/lead` проверяет имя, телефон и согласие. Для реальной отправки настройте серверную переменную `LEAD_WEBHOOK_URL` (HTTPS endpoint CRM/форм). Без подключения сервер возвращает 503, а интерфейс честно сообщает, что заявка не отправлена. Состояние успеха показывается только после подтверждённого ответа сервиса. Персональные данные не сохраняются в браузере.

Перед приёмом заявок опубликуйте утверждённые политику и согласие; настройте защиту webhook от спама и ограничения запросов в инфраструктуре при публичном запуске.

## Запуск

`npm run dev`, `npm run build`.

Калькулятор использует демонстрационные коэффициенты в `site.calculator`. Диапазон ориентировочный, без автоматической отправки данных. Поддержка WebMCP включается только в совместимом браузере; инструмент `configure_ceiling_estimate` меняет те же параметры и показывает результат.
